# 鹈鹕骑自行车 · 3D

A pelican riding a bicycle — a procedurally generated real-time 3D scene.

- Everything is built from code at load time: no models, no textures on disk.
- The pelican's legs are solved with two-bone IK every frame and follow the pedals.
- Drag to orbit, scroll to zoom, space to pause, speed slider, and camera presets.

Built with Three.js. `index.html` is fully self-contained apart from the Three.js CDN import.
